# ⚽ Gestor de Pedidos - La Casa del Fútbol

Una aplicación web de gestión de inventario y ventas diseñada para controlar pedidos de camisetas de fútbol. Este proyecto ha sido desarrollado como parte de mi formación como desarrollador Full-Stack en Escuela Musk, enfocándose en la resolución de problemas lógicos de negocio y la creación de interfaces de usuario funcionales.

## 🚀 Características Principales

- **Registro de Ventas (CRUD):** Creación y visualización de nuevos pedidos en tiempo real.
- **Gestión de Stock:** Contador dinámico que calcula automáticamente el volumen de camisetas necesarias por cada talla (S, M, L, XL).
- **Control de Pagos:** Seguimiento visual inmediato de los clientes que han pagado en efectivo frente a los que tienen pagos pendientes.
- **Eliminación de Registros:** Capacidad para borrar pedidos erróneos o cancelados, actualizando el inventario al instante.

## 💻 Tecnologías Utilizadas

- **Frontend:** HTML5 semántico y CSS3 (Diseño responsivo, Flexbox, variables de estado).
- **Lógica de Negocio:** JavaScript (Manipulación del DOM, arrays, objetos, renderizado dinámico y eventos).
- **Despliegue:** Vercel (Integración continua para mantener la beta privada y actualizada).

## 🧠 Aprendizajes Técnicos

Durante el desarrollo de esta aplicación, he consolidado conceptos clave de programación:
1. Conexión de interfaces de usuario (UI) con estructuras de datos estructuradas en JavaScript.
2. Iteración de arrays mediante bucles `for` para la renderización dinámica de elementos en el DOM.
3. Gestión del estado de la aplicación (añadir y filtrar elementos sin recargar la página mediante `event.preventDefault()`).
